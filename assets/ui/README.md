# UI assets

`revive` contains the six transparent Korean status images used for the local player's
revive countdown. They were rasterized with the Windows Malgun Gothic system font; the
font file itself is not copied or distributed with this project.

`skills` contains the transparent character skill icons used by the cooldown-only skill
bar. The icons were created for this project with OpenAI image generation and do not
contain third-party game artwork.
