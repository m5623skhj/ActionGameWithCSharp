# LPC character sprites

These sprites were generated with the [Universal LPC Spritesheet Character Generator](https://liberatedpixelcup.github.io/Universal-LPC-Spritesheet-Character-Generator/).

The included component artwork is distributed under **OGA-BY 3.0**. Every selected layer for both characters lists OGA-BY 3.0 (or OGA-BY 3.0+) as an available license. Keep this file and each character's `CREDITS.txt` with redistributed copies.

## Characters

- `warrior/warrior.png`: male warrior with steel plate armour, dark hair, black trousers and boots, and a steel arming sword.
- `ranger/ranger.png`: female ranger with forest leather armour, red high ponytail, brown trousers and boots, a dark bow, and an arrow layer.

The exact generator URL and selected layers are recorded in each character's `source.json`.
The `animations` directories contain the idle, walk, jump, and character-specific attack
sheets exported by the generator's split-by-animation download. The game client loads these
files directly at startup.
